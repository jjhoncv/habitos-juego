Privacidad

Hábitos es un juego para niños. Está hecho para que nada de lo que tu hijo o hija hace en el juego salga de este dispositivo.

  • No pedimos cuentas, correos ni nombres reales. El nombre del personaje lo inventa el niño.
  • Todo se guarda solo en este navegador (almacenamiento local): el personaje, el día de la semana, las estrellas, el álbum y el cariño de la cachorrita. No se envía a ningún servidor.
  • No hay publicidad, ni rastreo, ni analítica.
  • Las voces las genera el propio navegador del dispositivo. El juego no usa el micrófono ni la cámara.
  • El juego descarga la librería 3D (three.js) desde cdnjs y las letras desde Google Fonts, como cualquier página web.
  • Para borrar todo: borra los datos de este sitio en la configuración del navegador.

Si algún día el juego guardara datos fuera del dispositivo, se pediría antes el permiso de un adulto, como indican las leyes de protección de datos de menores.
